# Reinforcement-Learning-Q-Learning

## Descripción
Este proyecto implementa un agente inteligente mediante el algoritmo **Q-Learning**, cuyo objetivo es aprender a encontrar la salida de un laberinto de 4 × 4, evitando obstáculos mediante un sistema de recompensas y penalizaciones.

## Tecnologías utilizadas
- Python
- NumPy
- Matplotlib
- Google Colab

## Implementación
El proyecto contempla:
- Creación del entorno del laberinto.
- Definición de estados, acciones y recompensas.
- Implementación del algoritmo Q-Learning.
- Entrenamiento del agente durante 500 episodios.
- Visualización de las recompensas y del recorrido aprendido.

## Resultados
El agente logró aprender un recorrido válido desde la posición inicial hasta la meta, evitando los obstáculos del laberinto.

## Ejecución
El proyecto se encuentra en el notebook `Reinforcement_Learning_Q_Learning.ipynb`, que puede ejecutarse directamente en Google Colab.
